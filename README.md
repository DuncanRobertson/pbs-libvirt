# pbs-libvirt

This project is hosted on Codeberg:

### **[https://codeberg.org/DuncanRobertson/pbs-libvirt](https://codeberg.org/DuncanRobertson/pbs-libvirt)**

Back up libvirt/KVM guests with raw LVM disks to
[Proxmox Backup Server](https://www.proxmox.com/en/proxmox-backup-server)
as Proxmox VE-compatible `vm/` snapshots, with PBS compression, deduplication
and encryption. Restores to libvirt or to Proxmox VE.
A single Python 3 script driving `proxmox-backup-client`, `virsh` and LVM.
